# Лабораторна робота №3. Створення адаптивного модального вікна

## 1. Структура компонентів
Застосунок побудований на базі ієрархічної структури компонентів Vue 3:
- `App.vue` — Кореневий компонент, який визначає загальну композицію сторінки.
  └── `MaterialCatalog.vue` — Головний логічний компонент, який зберігає стан (список матеріалів, фільтри, управління модальним вікном).
      ├── `MaterialFilterForm.vue` — Компонент форми для введення параметрів пошуку та фільтрації.
      ├── `MaterialCard.vue` — Компонент картки для відображення інформації про окремий матеріал та кнопок дій.
      └── `ModalDialog.vue` — Перевикористовуваний адаптивний компонент діалогового вікна (використовує `Teleport` та `Transition`).

## 2. Версії залежностей
Проєкт використовує наступні версії ключових технологій:
- **Node.js**: 24.x LTS
- **Vue**: ^3.4.x
- **Tailwind CSS**: 3.4.17
- **PostCSS**: 8.5.6
- **Autoprefixer**: 10.4.21

## 3. Команди запуску та збірки

Встановлення всіх необхідних залежностей:
```bash
npm install
```

Запуск локального сервера для розробки:
```bash
npm run dev -- --port 5173 --strictPort
```

Створення оптимізованої виробничої збірки проєкту:
```bash
npm run build
```

Локальний перегляд зібраного проєкту:
```bash
npm run preview -- --port 4173 --strictPort
```

## 4. Опис контракту компонента ModalDialog
Компонент розроблено як універсальну обгортку, що не залежить від конкретних бізнес-даних.
- **Props (Вхідні параметри)**:
  - `modelValue` (Boolean) — керує станом вікна (відкрито/закрито).
  - `title` (String) — текст заголовка діалогового вікна.
  - `initialFocus` (Object | HTMLElement) — шаблонне посилання на елемент, який має отримати фокус під час відкриття вікна.
  - `fallbackFocus` (Object | HTMLElement) — шаблонне посилання на елемент, на який повернеться фокус після закриття (якщо елемент виклику недоступний).
- **Emits (Події)**:
  - `update:modelValue` — подія, яка надсилається в батьківський компонент для синхронізації стану закриття (через `v-model`).
- **Slots (Слоти)**:
  - `default` (неіменований слот) — основна область для контенту (текст підтвердження, форма тощо).
  - `footer` (іменований слот) — область внизу вікна для розміщення елементів керування (кнопок Скасувати, Зберегти, Видалити).
