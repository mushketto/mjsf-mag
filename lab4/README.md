# Лабораторна робота №4. Створення вкладок із використанням Slots, Provide/Inject, dynamic components і KeepAlive

## 1. Структура компонентів

Застосунок побудований на базі складеного компонента (compound component) та ізольованих демонстраційних панелей у Vue 3:

* `App.vue` — Кореневий компонент, що містить блок ідентифікації автора/середовища та три незалежні набори вкладок (`underline`, `pills`, `boxed`).
├── `Tabs.vue` — Батьківський контейнер вкладок, який володіє активним станом, формує навігацію WAI-ARIA та надає локальний контекст через `provide`.
│   └── `Tab.vue` — Дочірній компонент декларації вкладки, що реєструється через `inject` і рендерить панель через слот або `<component :is>` із кешуванням `<KeepAlive>`.
├── `tabsKey.js` — Окремий модуль із ключем ін'єкції `Symbol('tabs')` для безпечного зв'язку між `Tabs` та `Tab`.
└── `demo-panels/` — Панелі вмісту з власним реактивним локальним станом:
├── `OverviewPanel.vue` — Панель із текстовим полем нотатки та лічильником активацій (`onActivated`).
├── `RequirementsPanel.vue` — Панель зі списком контрольних вимог, прапорцями та лічильником виконаних пунктів.
└── `EnvironmentPanel.vue` — Панель із даними середовища та викликом перенесеного діалогового вікна `ModalDialog.vue`.

## 4. Опис контрактів компонентів Tabs та Tab

### Контракт контейнера `Tabs.vue`

Компонент відповідає за відображення смуги кнопок (`role="tablist"`), управління активною вкладкою та роздачу ізольованого контексту.

* **Props (Вхідні параметри)**:


* `modelValue` (String, обов'язковий) — `slug` поточної активної вкладки.


* `variant` (String, за замовчуванням `'underline'`) — варіант візуального оформлення (`'underline'`, `'pills'`, `'boxed'`).




* **Emits (Події)**:


* `update:modelValue` — надсилає `slug` нової активної вкладки під час вибору кнопкою миші або клавіатурою.




* **Slots (Слоти)**:


* `default` — приймає дочірні декларації `<Tab>` та відображає їхні панелі під смугою навігації.




* **Provide (Контекст через `tabsKey`)**:


* `activeSlug` (readonly ref) — реактивний ідентифікатор активної вкладки.


* `idPrefix` (String) — унікальний префікс для зв'язування атрибутів `aria-controls` та `aria-labelledby`.


* `setActiveTab(slug)` — метод перемикання активної вкладки.


* `registerTab(tab)` / `unregisterTab(slug)` — методи життєвого циклу для реєстрації та видалення вкладок зі списку.





### Контракт декларації `Tab.vue`

Компонент описує окрему вкладку та керує відображенням і кешуванням її панелі (`role="tabpanel"`).

* **Props (Вхідні параметри)**:


* `slug` (String, обов'язковий) — унікальний ідентифікатор вкладки в межах одного набору.


* `title` (String, обов'язковий) — текст на кнопці навігації.


* `disabled` (Boolean, за замовчуванням `false`) — блокує вибір вкладки мишею та пропускає її при навігації клавіатурою.


* `panel` (Object | null, за замовчуванням `null`) — об'єкт компонента панелі для динамічного рендерингу через `<component :is>`.


* `panelProps` (Object, за замовчуванням `{}`) — об'єкт пропсів, що розгортаються на динамічний компонент через `v-bind`.




* **Slots (Слоти)**:


* `default` — статична розмітка або компонент панелі (має безумовний пріоритет над пропсом `panel`); передає пропс слота `:is-active`.





## 5. Пояснення механізму перевірки `<KeepAlive>`

У компоненті `Tab.vue` рендеринг панелі побудовано на комбінації `<KeepAlive>` та умови `v-if="isActive"` на дочірньому слоті або динамічному компоненті `<component :is="panel">`:

* На відміну від `v-show` (який лише приховує елемент через `display: none` і залишає його постійно змонтованим у DOM), директива `v-if` реально вилучає неактивну панель із DOM-дерева під час перемикання вкладки.


* Обгортка `<KeepAlive>` перехоплює момент демонтажу та зберігає екземпляр компонента в оперативній пам'яті замість його знищення, викликаючи хук `onDeactivated` (а при поверненні на вкладку — `onActivated`).


* Перевірити роботу кешування можна у **Vue DevTools** (вкладка *Components*): неактивні компоненти панелей відображаються у дереві з позначкою `inactive` / `kept-alive`, а введені в них дані (текст нотатки, прапорці, лічильник) зберігаються без втрат.
