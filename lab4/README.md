# Лабораторна робота №4. Створення вкладок із використанням Slots, Provide/Inject, dynamic components і KeepAlive

## 1. Структура компонентів
Застосунок побудований на базі складеного компонента (compound component) та ізольованих демонстраційних панелей у Vue 3:

```text
App.vue — Кореневий компонент (блок ідентифікації автора/середовища та 3 незалежні набори вкладок: underline, pills, boxed)
├── components/
│   ├── tabs/
│   │   ├── Tabs.vue — Батьківський контейнер вкладок (активний стан, навігація WAI-ARIA, provide локального контексту)
│   │   ├── Tab.vue — Дочірня декларація вкладки (реєстрація через inject, рендеринг слотом або <component :is> із <KeepAlive>)
│   │   └── tabsKey.js — Окремий модуль із ключем ін'єкції Symbol('tabs')
│   ├── demo-panels/
│   │   ├── OverviewPanel.vue — Панель із текстовим полем нотатки та лічильником активацій (onActivated)
│   │   ├── RequirementsPanel.vue — Панель зі списком контрольних вимог, прапорцями та лічильником виконаних пунктів
│   │   └── EnvironmentPanel.vue — Панель із даними середовища та викликом модального вікна ModalDialog
│   └── ModalDialog.vue — Перенесений адаптивний компонент діалогового вікна з лабораторної роботи №3
```

## 4. Опис контрактів компонентів Tabs та Tab

### Контракт контейнера `Tabs.vue` (вузол IDEF0 A1 «Керувати вкладками»)
Компонент відповідає за відображення смуги кнопок (`role="tablist"`), управління активною вкладкою та надання ізольованого контексту нащадкам.

- **Props (Вхідні параметри)**:
  - `modelValue` (`String`, обов'язковий) — `slug` поточної активної вкладки.
  - `variant` (`String`, за замовчуванням `'underline'`) — варіант візуального оформлення (`'underline'`, `'pills'`, `'boxed'`).
  - `ariaLabel` (`String`, за замовчуванням `'Навігація вкладками'`) — доступна назва списку вкладок для скрінрідерів.
- **Emits (Події)**:
  - `update:modelValue` — надсилає `slug` нової активної вкладки під час вибору кнопкою миші або клавіатурою.
- **Slots (Слоти)**:
  - `default` — приймає дочірні декларації `<Tab>` та відображає їхні панелі під навігаційною смугою.
- **Provide (Контекст через `tabsKey`)**:
  - `activeSlug` (`readonly ref`) — реактивний ідентифікатор активної вкладки.
  - `idPrefix` (`String`) — унікальний префікс для зв'язування атрибутів `aria-controls` та `aria-labelledby`.
  - `setActiveTab(slug)` — метод перемикання активної вкладки.
  - `registerTab({ slug, title, disabled })` / `unregisterTab(slug)` — методи життєвого циклу для реєстрації та видалення вкладок зі списку.

### Контракт декларації `Tab.vue` (вузол IDEF0 A2 «Показати панель»)
Компонент описує окрему вкладку та керує відображенням і кешуванням її панелі (`role="tabpanel"`).

- **Props (Вхідні параметри)**:
  - `slug` (`String`, обов'язковий) — унікальний ідентифікатор вкладки в межах одного набору.
  - `title` (`String`, обов'язковий) — напис на кнопці навігації.
  - `disabled` (`Boolean`, за замовчуванням `false`) — блокує вибір вкладки мишею та пропускає її під час навігації клавіатурою.
  - `panel` (`Object | null`, за замовчуванням `null`) — об'єкт компонента панелі для динамічного рендерингу через `<component :is>`.
  - `panelProps` (`Object`, за замовчуванням `{}`) — об'єкт параметрів, що розгортаються на динамічний компонент через `v-bind`.
- **Slots (Слоти)**:
  - `default` — статична розмітка або компонент панелі (має безумовний пріоритет над пропсом `panel`); передає пропс слота `:is-active`.

## 5. Пояснення механізму перевірки `<KeepAlive>`
У компоненті `Tab.vue` відображення панелі побудовано на комбінації `<KeepAlive>` та директиви `v-if="isActive"` на дочірньому слоті або динамічному компоненті `<component :is="panel">`:

- На відміну від `v-show` (який лише приховує елемент через `display: none` і залишає його постійно змонтованим у DOM), умова `v-if` реально вилучає неактивну панель із DOM-дерева під час перемикання вкладки.
- Обгортка `<KeepAlive>` перехоплює момент вилучення та зберігає екземпляр компонента в кеші оперативної пам'яті замість його знищення, викликаючи хук `onDeactivated` (а при поверненні на вкладку — `onActivated`).
- Перевірити роботу кешування можна у **Vue DevTools** (вкладка *Components*): неактивні панелі відображаються у дереві з позначкою `inactive` / `kept-alive`, а локальні дані (введена нотатка, прапорці, лічильник) повністю зберігаються після повернення.

| Перевірка | Очікуваний результат | Фактичний результат |
| :--- | :--- | :--- |
| **Три варіанти та незалежність** | На сторінці одночасно відображаються набори `underline`, `pills` і `boxed`; перемикання вкладки в одному наборі не змінює активні вкладки двох інших. | Відповідає очікуваному |
| **Збереження стану (`KeepAlive`)** | Після введення тексту нотатки, зміни прапорців чи лічильника, переходу на іншу вкладку та повернення назад усі введені дані зберігаються. | Відповідає очікуваному |
| **Динамічні панелі та слоти** | Набір `underline` коректно відображає панелі зі слотів, а набір `pills` — динамічно згенеровані панелі з масиву через `<component :is>`. | Відповідає очікуваному |
| **Клавіатура та WAI-ARIA** | Клавіша `Tab` фокусує активну вкладку; `ArrowLeft`, `ArrowRight`, `Home`, `End` циклічно перемикають вкладки та активують панелі, пропускаючи `disabled`. | Відповідає очікуваному |
| **Робота `ModalDialog`** | Діалогове вікно відкривається з панелі `EnvironmentPanel` у наборі `boxed` та закривається без втрати локального стану обох екземплярів панелі. | Відповідає очікуваному |
| **Адаптивність екрана** | На ширинах `360×800`, `768×1024`, `1440×900` та `844×390` відсутня горизонтальна прокрутка сторінки, текст вкладок і модального вікна не обрізається. | Відповідає очікуваному |
